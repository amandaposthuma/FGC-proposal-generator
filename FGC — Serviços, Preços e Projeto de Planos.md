## 3.2 O que medir em cada item marcado

Para cada caixa marcada, responder cinco coisas:

| Pergunta | Por que importa |
|---|---|
| Quem faz? (Claudia / Fabiana / Meire / terceiro) | Define o custo-hora |
| Quanto tempo leva por vez? | Base do custo |
| Quantas vezes por ano, por cliente? | Vira custo anual |
| Quantos % dos clientes usam? | Separa o universal do excepcional |
| Quem puxa: o cliente, a FGC, ou a lei? | Diz se dá para controlar o volume |

**Custo oculto por cliente/ano = Σ (tempo × frequência × custo-hora)**

Esse número é a resposta para "quanto estamos deixando na mesa" — e é o que
justifica o preço do plano.

## 3.3 Onde cada serviço vai parar

| Destino | Critério |
|---|---|
| **Incluído no plano base** | Frequente, barato, todo cliente espera |
| **Incluído em plano superior** | Custo médio, é diferenciador, nem todo cliente precisa |
| **Cobrado sempre à parte** | Caro, esporádico, o gatilho é externo |

**A analogia da Claudia, aplicada:** plano base são as aulas — todo mundo tem,
está no preço. Plano superior é a sauna inclusa. Avulso é a sauna comprada por
dia. O ponto não é cobrar mais de todo mundo. É deixar visível, para que quem
usa mais pague mais e quem usa pouco perceba que economiza.
